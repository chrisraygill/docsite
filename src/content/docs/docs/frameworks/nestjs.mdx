Use this guide when you're starting from a NestJS app and want to expose Genkit flows as HTTP endpoints.

## Before you begin

- Node.js v20 or later
- npm

This guide assumes you're already familiar with building NestJS applications.

## Create a project

If you don't already have a NestJS project, create one:

<PackageManagerTabs command={`
npx @nestjs/cli new my-genkit-nestjs
cd my-genkit-nestjs
`} />

When prompted, choose your preferred package manager.



## Install Genkit packages

Install the Genkit CLI globally:

<PackageManagerTabs command="npm install -g genkit-cli" />

Then install the packages you need in your project:

<PackageManagerTabs command={`
npm install genkit @genkit-ai/google-genai @genkit-ai/fetch
npm install -D tsx
`} />

## Configure your model API key

This guide uses the Gemini API from Google AI Studio.

```bash
export GEMINI_API_KEY=<your API key>
```

## Define your recipe flow

Create `src/genkit/recipeGeneratorFlow.ts`:

```ts title="src/genkit/recipeGeneratorFlow.ts"
import { googleAI } from '@genkit-ai/google-genai';
import { genkit, z } from 'genkit';

const ai = genkit({
  plugins: [googleAI()],
  model: googleAI.model('gemini-flash-latest', {
    temperature: 0.8,
  }),
});

const RecipeInputSchema = z.object({
  ingredient: z.string().describe('Main ingredient or cuisine type'),
  dietaryRestrictions: z
    .string()
    .optional()
    .describe('Any dietary restrictions'),
});

const RecipeSchema = z.object({
  title: z.string(),
  description: z.string(),
  prepTime: z.string(),
  cookTime: z.string(),
  servings: z.number(),
  ingredients: z.array(z.string()),
  instructions: z.array(z.string()),
  tips: z.array(z.string()).optional(),
});

export const recipeGeneratorFlow = ai.defineFlow(
  {
    name: 'recipeGeneratorFlow',
    inputSchema: RecipeInputSchema,
    outputSchema: RecipeSchema,
  },
  async (input) => {
    const prompt = `Create a recipe with the following requirements:
      Main ingredient: ${input.ingredient}
      Dietary restrictions: ${input.dietaryRestrictions || 'none'}`;

    const { output } = await ai.generate({
      prompt,
      output: { schema: RecipeSchema },
    });

    if (!output) throw new Error('Failed to generate recipe');
    return output;
  },
);
```

## Create a controller

Create `src/genkit/genkit.controller.ts` to expose the flow using Genkit's fetch handler:

```ts title="src/genkit/genkit.controller.ts"
import { Controller, Post, Req, Res } from '@nestjs/common';
import { Request, Response } from 'express';
import { recipeGeneratorFlow } from './recipeGeneratorFlow';
import { fetchHandlers } from '@genkit-ai/fetch';
import { Readable } from 'node:stream';

const handleFlow = fetchHandlers([recipeGeneratorFlow], '/genkit');

@Controller('genkit')
export class GenkitController {
  @Post('*')
  async handleGenkit(@Req() req: Request, @Res() res: Response) {
    // Convert Express request to Web Request
    const url = new URL(req.url, `${req.protocol}://${req.get('host')}`);
    const headers = new Headers();
    for (const [key, value] of Object.entries(req.headers)) {
      if (value === undefined) continue;
      if (Array.isArray(value)) {
        value.forEach((v) => headers.append(key, v));
      } else {
        headers.set(key, String(value));
      }
    }

    const webRequest = new Request(url, {
      method: req.method,
      headers,
      body:
        req.method !== 'GET' && req.method !== 'HEAD'
          ? JSON.stringify(req.body)
          : undefined,
    });

    const webResponse = await handleFlow(webRequest);
    res.status(webResponse.status);
    webResponse.headers.forEach((value, key) => {
      res.setHeader(key, value);
    });

    if (webResponse.body) {
      Readable.fromWeb(webResponse.body).pipe(res);
    } else {
      res.end();
    }
  }
}
```

NestJS uses Express under the hood. The controller converts the Express `Request` to a Web `Request` that `fetchHandlers` expects, then streams the Web `Response` back through Express.

## Register the controller

Add the `GenkitController` to your `AppModule`:

```ts title="src/app.module.ts"
import { Module } from '@nestjs/common';
import { GenkitController } from './genkit/genkit.controller';

@Module({
  controllers: [GenkitController],
})
export class AppModule {}

## Run your application

Run your app locally:

<PackageManagerTabs command="npm run start:dev" />

You can also launch the Developer UI alongside your flow code:

<PackageManagerTabs command="genkit start -- npx tsx --watch src/genkit/recipeGeneratorFlow.ts" />

## Test your flow

With the server running, call your flow over HTTP:

```bash
curl -X POST http://localhost:3000/genkit/recipeGeneratorFlow \
  -H "Content-Type: application/json" \
  -d '{"data":{"ingredient":"avocado","dietaryRestrictions":"vegetarian"}}'
```

You should receive a structured recipe in the response.

## Test in the Developer UI

The **Developer UI** is a local tool for testing and inspecting Genkit components, like flows, with a visual interface.

### Start the Developer UI

The Genkit CLI is required to run the Developer UI. If you followed the installation steps above, you already have it installed.

Run the following command from your project root:

<PackageManagerTabs command="genkit start -- npx tsx --watch src/genkit/recipeGeneratorFlow.ts" />

This starts your app and launches the Developer UI at `http://localhost:4000` by default.

:::note
The command after `--` should run the file that defines or imports your Genkit components. You can use `tsx`, `node`, or other commands based on your setup. Learn more in [developer tools](/docs/devtools).
:::

##### Optional: Add an npm script

To make starting the Developer UI easier, add the following to your `package.json` scripts:

```json
"scripts": {
  "genkit:ui": "genkit start -- npx tsx --watch src/genkit/recipeGeneratorFlow.ts"
}
```

Then run it with:

<PackageManagerTabs command="npm run genkit:ui" />
