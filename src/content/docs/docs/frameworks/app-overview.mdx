Pick the app framework or client SDK that matches the UI you're building. Each guide is self-contained and shows how to call a Genkit flow from a frontend, either by hosting the flow inside the framework's own server-side routes or by connecting to a standalone Genkit backend.

## Full-stack JavaScript frameworks

These frameworks can host your Genkit flow inside their own server routes, or call a standalone backend over HTTP.

- [Angular](/docs/frameworks/angular) for Angular SSR and hybrid-rendered apps.
- [Next.js](/docs/frameworks/nextjs) for full-stack React apps, with paths for App Router, Pages Router, or a standalone Genkit backend.
- [SvelteKit](/docs/frameworks/sveltekit) for full-stack Svelte apps using SvelteKit endpoints and the Genkit fetch handler.
- [Nuxt](/docs/frameworks/nuxt) for full-stack Vue apps using Nitro server routes and the Genkit fetch handler.
- [Remix](/docs/frameworks/remix) for full-stack React apps using Remix resource routes and the Genkit fetch handler.
- [TanStack Start](/docs/frameworks/tanstack-start) for full-stack React apps using TanStack Router API routes.
- [Astro](/docs/frameworks/astro) for content-driven sites using Astro SSR with API routes.

## Client-only frameworks

These frameworks run entirely in the browser and always connect to a standalone Genkit backend in any language.

- [React (Vite)](/docs/frameworks/react) for client-side React apps that connect to a standalone Genkit backend.

## Mobile and Flutter

- [Flutter](/docs/frontend/flutter) to call Genkit flows from a Flutter mobile, desktop, or web app.

## Plain JavaScript or TypeScript

- [Web client](/docs/frontend/web-client) to call flows from any JavaScript or TypeScript web app without a framework.
