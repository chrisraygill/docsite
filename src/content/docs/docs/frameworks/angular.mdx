Use this guide to learn how to add AI-powered features to an Angular application with Genkit.

<Lang lang="js">

You can integrate Genkit in two ways:

- **Angular SSR**: Run Genkit server-side directly inside Angular SSR server routes.
- **Standalone backend**: Connect your Angular frontend to a standalone JS/TS backend server (e.g., Express or Hono).

### Define your recipe flow

Create `src/genkit/recipeGeneratorFlow.ts`:

```ts title="src/genkit/recipeGeneratorFlow.ts"
import { googleAI } from '@genkit-ai/google-genai';
import { genkit, z } from 'genkit';

const ai = genkit({
  plugins: [googleAI()],
  model: googleAI.model('gemini-flash-latest', {
    temperature: 0.8,
  }),
});

const RecipeInputSchema = z.object({
  ingredient: z.string().describe('Main ingredient or cuisine type'),
  dietaryRestrictions: z
    .string()
    .optional()
    .describe('Any dietary restrictions'),
});

const RecipeSchema = z.object({
  title: z.string(),
  description: z.string(),
  prepTime: z.string(),
  cookTime: z.string(),
  servings: z.number(),
  ingredients: z.array(z.string()),
  instructions: z.array(z.string()),
  tips: z.array(z.string()).optional(),
});

export const recipeGeneratorFlow = ai.defineFlow(
  {
    name: 'recipeGeneratorFlow',
    inputSchema: RecipeInputSchema,
    outputSchema: RecipeSchema,
  },
  async (input) => {
    const prompt = `Create a recipe with the following requirements:
      Main ingredient: ${input.ingredient}
      Dietary restrictions: ${input.dietaryRestrictions || 'none'}`;

    const { output } = await ai.generate({
      prompt,
      output: { schema: RecipeSchema },
    });

    if (!output) throw new Error('Failed to generate recipe');
    return output;
  },
);
```

### Add a server route

Register the flow handler in `src/server.ts`:

```ts title="src/server.ts"
// ...
import { expressHandler } from '@genkit-ai/express';
import { recipeGeneratorFlow } from './genkit/recipeGeneratorFlow';

// ...
const app = express(); // Existing Angular SSR setup

app.use(express.json());
app.post('/api/recipeGeneratorFlow', expressHandler(recipeGeneratorFlow));
```

## Call your flow from an Angular component

Whether using Angular SSR or a standalone backend, update your component to call the flow endpoint:

### Component class

Replace the contents of `src/app/app.component.ts` with the following:

```ts title="src/app/app.component.ts"
import { Component, signal } from '@angular/core';
import { FormsModule } from '@angular/forms';
import { JsonPipe } from '@angular/common';
import { runFlow } from 'genkit/beta/client';

@Component({
  selector: 'app-root',
  imports: [FormsModule, JsonPipe],
  templateUrl: './app.component.html',
})
export class AppComponent {
  ingredient = signal('avocado');
  dietaryRestrictions = signal('vegetarian');
  recipe = signal<any | null>(null);

  async generateRecipe() {
    const result = await runFlow({
      // For JS SSR, use relative URL: '/api/recipeGeneratorFlow'
      // For standalone backends, use absolute URL: 'http://localhost:3000/recipeGeneratorFlow'
      url: '/api/recipeGeneratorFlow',
      input: {
        ingredient: this.ingredient(),
        dietaryRestrictions: this.dietaryRestrictions(),
      },
    });

    this.recipe.set(result);
  }
}
```

This component uses Angular **Signals** to manage the form input states reactively. The `generateRecipe()` method calls the flow endpoint using Genkit's `runFlow` client helper and stores the resulting recipe.

:::caution[Enable CORS]
If you are using a standalone backend, enable CORS on your backend server or the browser will block requests from the Angular application.
:::

### Component template

Replace the contents of `src/app/app.component.html` with the following:

```angular title="src/app/app.component.html"
<main>
  <h1>Recipe generator</h1>
  <input
    [ngModel]="ingredient()"
    (ngModelChange)="ingredient.set($event)"
    placeholder="Ingredient"
  />
  <input
    [ngModel]="dietaryRestrictions()"
    (ngModelChange)="dietaryRestrictions.set($event)"
    placeholder="Dietary restrictions"
  />
  <button (click)="generateRecipe()">Generate recipe</button>

  @if (recipe()) {
    <pre>{{ recipe() | json }}</pre>
  }
</main>
```

The template uses two-way model binding to sync the input fields with the component signals, and binds the button click to `generateRecipe()`. Angular's modern **`@if`** control flow conditionally renders the output, utilizing the built-in **`json` pipe** to format the structured recipe JSON.

## Test your flow

Test the endpoint directly:

```bash
curl -X POST http://localhost:4200/api/recipeGeneratorFlow \
  -H "Content-Type: application/json" \
  -d '{"data":{"ingredient":"avocado","dietaryRestrictions":"vegetarian"}}'
```

You should receive a structured recipe in the response.

## Test in the Developer UI

Start the Developer UI from your project root:

```bash
npx genkit start -- npx tsx --watch src/genkit/recipeGeneratorFlow.ts
```

This launches the Developer UI at `http://localhost:4000` by default.

:::tip[Add an npm script]
To make starting the Developer UI easier, add this to your `package.json` scripts:

```json
"scripts": {
  "genkit:ui": "genkit start -- npx tsx --watch src/genkit/recipeGeneratorFlow.ts"
}
```

Then run: `npm run genkit:ui`
:::
