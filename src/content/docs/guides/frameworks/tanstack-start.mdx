Use this guide when you're starting from a TanStack Start app and want to add Genkit flows as API endpoints alongside your TanStack Router pages. You can either define Genkit flows directly in TanStack Start API routes, or connect your frontend to a standalone Genkit backend written in any language.

## Before you begin

- Node.js v20 or later
- npm

This guide assumes you're already familiar with building TanStack Start applications.

## Create a project

If you don't already have a TanStack Start project, create one:

```bash
npx create-start@latest my-genkit-tanstack
cd my-genkit-tanstack
npm install
```

## Connect to a standalone backend

Since your Genkit backend uses a different language, you'll set up the backend and frontend separately:

1. **Set up your backend** — follow a [server integration guide](/guides/frameworks/overview) for your language to create a Genkit server that exposes flows as HTTP endpoints.
2. **Call flows from TanStack Start** — use `runFlow` from the Genkit client library in your React components, pointing to your backend's URL.

### Install the client library

```bash
npm install genkit
```

### Call a flow

```tsx title="app/routes/index.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { useState } from 'react';
import { runFlow } from 'genkit/beta/client';

export const Route = createFileRoute('/')({
  component: Home,
});

function Home() {
  const [ingredient, setIngredient] = useState('avocado');
  const [dietaryRestrictions, setDietaryRestrictions] = useState('vegetarian');
  const [recipe, setRecipe] = useState<any>(null);

  async function generateRecipe() {
    const result = await runFlow({
      url: 'http://localhost:3000/recipeGeneratorFlow',
      input: { ingredient, dietaryRestrictions },
    });

    setRecipe(result);
  }

  return (
    <main>
      <h1>Recipe generator</h1>
      <input value={ingredient} onChange={(e) => setIngredient(e.target.value)} />
      <input
        value={dietaryRestrictions}
        onChange={(e) => setDietaryRestrictions(e.target.value)}
      />
      <button onClick={generateRecipe}>Generate recipe</button>
      {recipe && <pre>{JSON.stringify(recipe, null, 2)}</pre>}
    </main>
  );
}
```

Replace `http://localhost:3000` with your backend's address. See the [Web client](/guides/frontend/web-client) guide for streaming and advanced patterns.

## Install Genkit packages

Install the Genkit CLI globally:

```bash
npm install -g genkit-cli
```

Then install the packages you need in your project:

```bash
npm install genkit @genkit-ai/google-genai @genkit-ai/fetch
npm install -D tsx
```

## Configure your model API key

This guide uses the Gemini API from Google AI Studio.

```bash
export GEMINI_API_KEY=<your API key>
```

## Define your recipe flow

Create `app/genkit/recipeGeneratorFlow.ts`:

```ts title="app/genkit/recipeGeneratorFlow.ts"
import { googleAI } from '@genkit-ai/google-genai';
import { genkit, z } from 'genkit';

const ai = genkit({
  plugins: [googleAI()],
  model: googleAI.model('gemini-2.5-flash', {
    temperature: 0.8,
  }),
});

const RecipeInputSchema = z.object({
  ingredient: z.string().describe('Main ingredient or cuisine type'),
  dietaryRestrictions: z
    .string()
    .optional()
    .describe('Any dietary restrictions'),
});

const RecipeSchema = z.object({
  title: z.string(),
  description: z.string(),
  prepTime: z.string(),
  cookTime: z.string(),
  servings: z.number(),
  ingredients: z.array(z.string()),
  instructions: z.array(z.string()),
  tips: z.array(z.string()).optional(),
});

export const recipeGeneratorFlow = ai.defineFlow(
  {
    name: 'recipeGeneratorFlow',
    inputSchema: RecipeInputSchema,
    outputSchema: RecipeSchema,
  },
  async (input) => {
    const prompt = `Create a recipe with the following requirements:
      Main ingredient: ${input.ingredient}
      Dietary restrictions: ${input.dietaryRestrictions || 'none'}`;

    const { output } = await ai.generate({
      prompt,
      output: { schema: RecipeSchema },
    });

    if (!output) throw new Error('Failed to generate recipe');
    return output;
  },
);
```

## Create an API route

Create `app/routes/api/recipeGeneratorFlow/[...path].ts` to expose the flow using Genkit's fetch handler:

```ts title="app/routes/api/recipeGeneratorFlow/[...path].ts"
import { createAPIFileRoute } from '@tanstack/react-start/api';
import { recipeGeneratorFlow } from '~/genkit/recipeGeneratorFlow';
import { fetchHandlers } from '@genkit-ai/fetch';

const handleFlow = fetchHandlers(
  [recipeGeneratorFlow],
  '/api/recipeGeneratorFlow',
);

export const APIRoute = createAPIFileRoute(
  '/api/recipeGeneratorFlow/$',
)({
  POST: async ({ request }) => {
    return handleFlow(request);
  },
});
```

TanStack Start API routes receive a standard Web `Request` object, so `fetchHandlers` works directly without any adapter.

## Run your application

Run your app locally:

```bash
npm run dev
```

You can also launch the Developer UI alongside your flow code:

```bash
genkit start -- npx tsx --watch app/genkit/recipeGeneratorFlow.ts
```

## Test your flow

With the server running, call your flow over HTTP:

```bash
curl -X POST http://localhost:3000/api/recipeGeneratorFlow \
  -H "Content-Type: application/json" \
  -d '{"data":{"ingredient":"avocado","dietaryRestrictions":"vegetarian"}}'
```

You should receive a structured recipe in the response.

## Test in the Developer UI

The **Developer UI** is a local tool for testing and inspecting Genkit components, like flows, with a visual interface.

### Start the Developer UI

The Genkit CLI is required to run the Developer UI. If you followed the installation steps above, you already have it installed.

Run the following command from your project root:

```bash
genkit start -- npx tsx --watch app/genkit/recipeGeneratorFlow.ts
```

This starts your app and launches the Developer UI at `http://localhost:4000` by default.

:::note
The command after `--` should run the file that defines or imports your Genkit components. You can use `tsx`, `node`, or other commands based on your setup. Learn more in [developer tools](/docs/devtools).
:::

### Run and inspect flows

In the Developer UI:

1. Select `recipeGeneratorFlow` from the list of flows.
2. Enter sample input:

   ```json
   {
     "ingredient": "avocado",
     "dietaryRestrictions": "vegetarian"
   }
   ```

3. Click **Run**

   You'll see the generated recipe as structured output, along with a visual trace of the AI generation process for debugging and optimization.
